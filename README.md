## Where to Do Your Work

Do all your work in **your own personal GitHub repository**, not in this one.

- Keep one folder per task in your personal repository, for example:

  ```text
  your-repository/
  ├── Task1/
  └── Task2/
  ```

- **Do not** upload completed solutions to this central repository. It is only used for task statements, provided resources, and submission Issues.

## How to Submit

1. Complete the task.
2. Commit and push your work to your personal repository.
3. Open this repository on GitHub.
4. Go to **Issues → New Issue → Task Submission**.
5. Fill in the form.
6. Submit the direct link to the relevant task folder in your repository.
