# Task 3 System Requirements and Learning Resources

## System Requirements

The following software environment is required to complete this task.

| Component | Requirement |
| --- | --- |
| Operating System | Ubuntu 24.04 LTS (64-bit) |
| ROS 2 Distribution | ROS 2 Jazzy Jalisco |
| Programming Language | Python 3 |
| Build Tool | colcon |
| ROS 2 Build System | ament_python |
| Visualization Tool | rqt_graph |
| Version Control | Git and GitHub |

All implementations must use **ROS 2 Jazzy and Python**. Other ROS 2 distributions are not recommended for this task.

### Verify Your Environment

Before beginning, verify that ROS 2 is installed and functioning correctly.

Run:

```bash
source /opt/ros/jazzy/setup.bash
ros2 --help
```

You should be able to execute ROS 2 commands without errors.

If ROS 2 is not installed, follow the official installation guide provided below.
